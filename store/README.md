# Thư mục `store/` — tài nguyên đăng Google Play

| File / thư mục | Dùng cho | Yêu cầu của Play |
|---|---|---|
| `play-store-icon-512.png` | Biểu tượng ứng dụng (Store listing → App icon) | PNG 512×512, ≤ 1 MB |
| `feature-graphic-1024x500.png` | Ảnh bìa (Feature graphic) | PNG/JPEG 1024×500 |
| `screenshots/phone/` | Ảnh chụp điện thoại | 2–8 ảnh, cạnh ngắn ≥ 320 px, cạnh dài ≤ 3840 px, tỉ lệ ≤ 2:1 |
| `screenshots/tablet-7in/` | Ảnh máy tính bảng 7" (tùy chọn) | như trên |
| `screenshots/tablet-10in/` | Ảnh máy tính bảng 10" (tùy chọn) | như trên |

## Gợi ý 8 ảnh chụp điện thoại (đặt tên theo thứ tự)
1. `01-home-light.png` — màn hình chính: slide 4 nhóm, đồng hồ đổi sau 5 phút
2. `02-home-dark.png` — chế độ tối
3. `03-menu.png` — menu 4 nhóm → 34 chủ đề
4. `04-search.png` — tìm kiếm (gõ không dấu, ví dụ “day an toan”)
5. `05-item.png` — chi tiết một mục (xếp hạng, nói đơn giản, chi phí, lợi ích)
6. `06-currency.png` — giá đã quy đổi (ví dụ chọn English → USD)
7. `07-tts.png` — đang nghe đọc
8. `08-favorites.png` — danh sách yêu thích

## Cách chụp
- Dùng emulator Pixel (API 36) hoặc máy thật; bật **Demo mode** để thanh trạng thái sạch (pin đầy, giờ 9:41).
- Dùng quảng cáo thử nghiệm của Google hoặc tắt mạng để ảnh không có banner thử nghiệm.
- Không chụp thông tin cá nhân. Đặt ảnh vào đúng thư mục con ở trên rồi tải lên Play Console.
